# Information-aware Adaptive Persistence research

SYNTHETIC_ENGINEERING_TEST. No restricted or real data is admitted. This package
asks which information could make forecasting possible; it does not claim that
its artificial intent channel exists or is useful in real repositories.

The integrated predictor starts from current debt and applies a validation-admitted
fraction of a conditional signed-delta median. It can abstain to persistence when
signals are absent, incomplete, unavailable at origin or insufficiently supported.
Stress admission also considers paired development futures with hidden or reversed
relationships. A time-valid signal can still fail under unobservable concept shift.

A new experiment needs its own registration and authorization; the published study
is consumed. Parent directories must already exist. Preparation refuses an existing
study path. Run refuses an existing admission/claim/output. No automatic retry.
The CLI has no real-data, service, download or pretrained-model route.

Full inputs, labels, fitted synthetic distributions and predictions remain outside
Git. Requests contain neither labels nor partition/family metadata. Artifacts are
written exclusively, synced, bounded and hashed. All final prediction populations
are sealed before label scoring. Logical access boundaries are auditable but do
not prevent malicious code with filesystem access from opening target files.
