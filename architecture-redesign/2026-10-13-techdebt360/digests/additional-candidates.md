# Additional candidate screen

Accessed 2026-10-13. Primary publisher cards, configs and live Hub metadata were inspected read-only. No downloads, inference or installation. This screen checks newer options rather than assuming the requested list contains the strongest current model. It is not an accuracy comparison.

## Qwen3-Coder-30B-A3B-Instruct

[Qwen card](https://huggingface.co/Qwen/Qwen3-Coder-30B-A3B-Instruct) describes instruction-based agentic coding with a 262,144-token native context. It returns generated text/tool-format suggestions, not debt classifications. Active parameters do not determine total storage. [Live metadata](https://huggingface.co/api/models/Qwen/Qwen3-Coder-30B-A3B-Instruct) exposes 30,532,122,624 BF16 parameters, 16 safetensors shards, Apache-2.0, revision `b2cff646eb4bb1d68355c01b18ae02e7cf42d120`, modified 2025-12-03. [Config](https://huggingface.co/Qwen/Qwen3-Coder-30B-A3B-Instruct/blob/main/config.json) identifies the MoE architecture; the card requires Transformers at least 4.51 recognition. Raw weights are about 61.06 GB, and an ideal four-bit payload is 15.27 GB before overhead (estimates). No latency/VRAM or technical-debt repair result was measured. Prefer this as a later capacity challenger if hardware and matched patch outcomes justify it; it is not the small default, and its tool outputs never execute directly. Publisher claims of broad coding strength do not establish maintainability remediation superiority.

## Qwen3.5-9B

[Qwen card](https://huggingface.co/Qwen/Qwen3.5-9B) describes a newer post-trained multimodal generator, with text-only use possible and thinking enabled by default. It is not specifically a technical-debt classifier. The advertised large context cannot be credited in a short-budget study automatically. [Metadata](https://huggingface.co/api/models/Qwen/Qwen3.5-9B) exposes four weight shards, 9,653,104,368 total parameters, Apache-2.0 and revision `c202236235762e1c871ad0ccb60c8ee5ba337b9a` (2026-03-02). [Config](https://huggingface.co/Qwen/Qwen3.5-9B/raw/main/config.json) identifies conditional generation, hybrid attention and a text context limit of 262,144. Raw BF16 weight payload is approximately 19.31 GB before overhead (estimate). The card currently points to recent/main serving frameworks, increasing reproducibility work. Benchmark it as **one optional same-budget M1/M7 challenger** to Qwen2.5-Coder 7B if a pinned runtime fits; preserve one final generator, not both. Freeze text formatting and final-answer extraction, nonthinking/thinking mode and total tokens. No primary evidence retrieved here proves it is better on this project's bounded Java patches; newest is not a selection result.

## TimesFM3.0-PyTorch

[Google repository](https://github.com/google-research/timesfm) describes an August 2026 release with native multivariate and covariate support, unlike the requested 2.5 target-only/XReg contract. Its public weights are restricted to noncommercial, nonproduction use; authorized Google Cloud serving has different terms. [Exact checkpoint](https://huggingface.co/google/timesfm-3.0-pytorch) and [metadata](https://huggingface.co/api/models/google/timesfm-3.0-pytorch) expose F32 weights for 330,710,976 parameters, revision `43046b85ec22d584a13f8098c2ed39c889e129c2` (2026-09-02). [Config](https://huggingface.co/google/timesfm-3.0-pytorch/raw/main/config.json) has input patches 32, output patches 64, nine decile quantiles, variate attention and maximum 32 variates. This does not establish a universal raw-context/horizon limit. Raw F32 weight payload is about 1.323 GB before activations. Its advantage is an actual native multivariate interface, not proven debt accuracy. Keep it as a later research-only covariate challenger after data gates; retain TimesFM 2.5 for the permissively licensed production-candidate comparison. Runtime/schema/cadence and true future-covariate availability still require verification.

## Screening decision

Qwen2.5-Coder 7B remains a reproducible small **starting candidate**, not an asserted current accuracy champion. Add at most one fitting newer challenger to the fixed-budget generator study, then choose one from independently verified outcomes. Neither more active models nor much longer context is a research contribution by itself. TimesFM3.0 can enter a licensed research experiment, but cannot silently replace the self-hosted production candidate. The primary architecture and capability gates remain unchanged.
