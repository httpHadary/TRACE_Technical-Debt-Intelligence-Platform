## Implementation

`forecasting_research/phase6_0/` contains strict immutable request/response contracts,
an evidence-backed registry,14-scenario generator, original statistical baseline
bridges, a read-only original-Chronos adapter wrapper, mathematical change-aware
interfaces, evaluator-only truth access, prediction sealing, checksummed artifact
publication, native repeatability and CPU/time/RSS/network controls. There is no
real-data loader, training command, dependency installer or external service.

All numerical inputs carry SYNTHETIC_ENGINEERING_TEST. The nominal unit remains
estimated maintainability remediation minutes, with an explicit synthetic status;
it is neither an actual analyzer observation nor developer repair effort. Future
truth/scenario metadata stays evaluator-side. Requests reject target/split fields,
future timestamps and mutable aliases; opaque case IDs avoid explicit scenario
hints. Sparse/irregular inputs retain their real generated observation timestamps
and masks. Chronos refuses them instead of manufacturing measured daily states.

The existing adapter/model configuration and locks were reused unchanged. Strict
whole-path native quantile ordering remains; no sorting, tolerance, recalibration
or hidden persistence fallback was added. Unexpected runtime/software failures abort.
