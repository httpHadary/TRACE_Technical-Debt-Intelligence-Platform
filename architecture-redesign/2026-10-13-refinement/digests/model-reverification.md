## Corrections that change admission

1. **TTM-r3 has actual pretrained short-context branches.** A family-wide 512-observation minimum is incorrect: directly checked weight-bearing branches support 52→16, 90→30, 180→60, and 360→60 observations. The previous digest's main=512 observation remains true but is insufficient for deciding family eligibility. Weekly 13-step forecasts can use 52 real weekly observations and trim a native 16-step forecast; daily 30/60 can use 90/180 real daily observations. Daily 90 needs the shortest checked eligible native branch, 512→96. These are admission conditions, not proof of accuracy. [IBM refs](https://huggingface.co/api/models/ibm-granite/granite-timeseries-ttm-r3/refs), [IBM catalogue](https://github.com/ibm-granite/granite-tsfm/blob/3d92535ca4138648b9d1e2f3f1421b5dec4dc3aa/tsfm_public/resources/model_paths_config/ttm.yaml).
2. **CodeAid is a 14.77B generative model, not a cheap classification head.** Its card lists Excessive Dependencies, while the public training-row output schema enumerates Feature Envy, Inappropriate Intimacy, Message Chains, and **Middle Man**. Resolve that mismatch before treating its output vocabulary as fixed. [Card](https://huggingface.co/CodeAid/CouplingSmells-Detection-model), [publisher dataset](https://huggingface.co/datasets/CodeAid/CouplingSmells-Detection-Data), [live schema](https://datasets-server.huggingface.co/first-rows?dataset=CodeAid%2FCouplingSmells-Detection-Data&config=default&split=train).
3. **Tesoro output semantics are reconstructed from author schema, not checkpoint label names.** Both requested checkpoints have four generic `LABEL_n` outputs, contradictory two-entry `label2id`, and `multi_label_classification`; the schema's ordered vector is DESIGN, IMPLEMENTATION, DEFECT, TEST. An all-zero output is permitted; it is not a calibrated clean/no-debt probability. [Graph config](https://huggingface.co/NamCyan/graphcodebert-base-technical-debt-code-tesoro/blob/edb7d422be19fe6cc420e01eed154225bb4cdfd8/config.json), [Code config](https://huggingface.co/NamCyan/codebert-base-technical-debt-code-tesoro/blob/849dd197ba21ba88651d400af95103c5bc30e21e/config.json), [author schema](https://github.com/NamCyan/tesoro/blob/main/data/README.md).
4. **Missing classifier license declarations are unresolved, not evidence of a noncommercial or forbidden license.** Keep candidates in the research shortlist; clarify permission before weight adoption. The Tesoro code repository's MIT license and a companion Space's license do not automatically license fine-tuned weights. [Tesoro license](https://github.com/NamCyan/tesoro/blob/main/LICENSE), [Graph API](https://huggingface.co/api/models/NamCyan/graphcodebert-base-technical-debt-code-tesoro), [Code API](https://huggingface.co/api/models/NamCyan/codebert-base-technical-debt-code-tesoro), [diff API](https://huggingface.co/api/models/davidgaofc/TechDebtClassifier).

## Experiment B: exact contracts and benchmark provenance

**GraphCodeBERT TD / CodeBERT TD — Java function debt types.** Author schema calls for normalized lowercase `cleancode` with newlines removed; RQ3 source recipe uses maximum 512 tokens and filters overlength examples. Both are `RobertaForSequenceClassification`, max positions 514. Apply independent sigmoid outputs, author threshold logit>0; label order is the four-entry schema above. The source path loads tokenized text, with no data-flow graph construction: GraphCodeBERT's name does not imply a graph service. Preserve raw source and line mapping separately because normalization removes location fidelity. [Schema](https://github.com/NamCyan/tesoro/blob/main/data/README.md), [recipe](https://github.com/NamCyan/tesoro/blob/main/training/scripts/RQ3/run.sh), [training/prediction code](https://github.com/NamCyan/tesoro/blob/main/training/cross_validation.py).

Paper v2 is dated 2025-08-09. Training recipe/current paper hyperparameters differ; no checkpoint-specific semantic mapping/reproducibility record was found. Graph is a rational *provisional aligned classifier* for a Java function pilot, while CodeBERT is its same-task control, not a second permanent detector. ## Smallest complementary active four: proposal, not selected winner

**Provisional pilot inference:** one GraphCodeBERT-Tesoro classifier for aligned Java function detection; one CodeRankEmbed encoder for source retrieval; one Qwen2.5-Coder-7B-Instruct generator for explanations/patch proposals; one Chronos-2-small forecaster for measured histories. These four serve different outputs, so complementarity does not imply an ensemble, summed debt score or voting. Graph's weight licensing is an open adoption condition; the plan does not declare permission solved. If Java function modality is not the real product task, replace the classifier choice through modality-specific evaluation instead of treating these results as multilingual proof.

Run **Experiment A first as a controlled model comparison**, keeping small Chronos provisional, full Chronos as capacity control, eligible TTM native branches as low-cost challengers, and TimesFM2.5 as independent univariate challenger. Include last-value/drift/justified seasonal baselines; score actual remediation-minute MAE and shared-quantile loss/coverage at identical origins/horizons. Compare common context separately from extended context. Weekly13/daily90 are different measured tasks; they cannot be merged by interpolation.
